# 報告書式

## 実装（implement）
```
pbi: <pbi-id>
status: done | blocked
branch: scrum/<pbi-id>
worktree: <作業ディレクトリの絶対パス>
summary: <変更概要>
tests: <実行したコマンドと結果>
assumptions:
  - <置いた仮定>
demo: <デモでの確かめ方。操作と見える結果>
unresolved:
  - <未解決事項>
```

## デザイン（design）
```
pbi: <pbi-id>
design: <UI 仕様ファイルの絶対パス>
summary: <仕様の要点>
assumptions:
  - <置いた仮定>
```
